1. Project Overview
The Student Performance Analysis Project analyses the examination performance of 30 students and compares the academic marks of students who use AI-based learning tools with those who do not.

The project uses Python for data processing, statistical analysis, graphical representation and interpretation of results.

All student names and academic records used in this project are dummy data created for educational and research practice. They do not represent actual students or examination results.

2. Main Dataset – StudentData.csv
The project uses StudentData.csv as its primary dataset.

The dataset contains the following information:
- Student ID
- Student Name
- Academic Year
- AI Learning Tool Usage
- Frequency of AI Tool Usage
- Weekly Study Hours
- Examination Marks
- Comparison Group (AI Tool Users / Non-AI Users)
Important: Keep StudentData.csv in the same folder as the Python source code before executing the analysis.

3. Work Completed
Task 1: Graphical Data Analysis and Interpretation
Task 1 focuses on analysing the examination marks of 30 students using Python.

The following activities were completed:
1. Imported and examined the student dataset.
2. Checked the total number of student records.
3. Classified examination marks into different score intervals.
4. Prepared a frequency distribution table.
5. Generated four graphical representations:
   - Histogram
   - Bar Chart
   - Pie Chart
   - Box Plot
6. Calculated descriptive statistical measures:
   - Mean
   - Median
   - Mode
   - Variance
   - Standard Deviation
7. Identified the highest and lowest marks, pass/fail counts and pass percentage.
8. Exported the frequency distribution and descriptive statistics into CSV files.

Task 2: Sampling, Observation and Surveys
Task 2 investigates how AI-based learning tools may influence students' academic performance.

The following components were prepared:
1. Research problem and research objectives.
2. Sampling plan covering students from different academic years.
3. Structured questionnaire containing questions about AI tool usage and study habits.
4. Explanation of survey and observation-based data collection methods.
5. Discussion of possible sampling errors and response bias.
A separate Word document containing the Task 2 research methodology was prepared.

Note: The questionnaire and sampling plan describe the proposed research procedure. The records in StudentData.csv are simulated data and are not actual questionnaire responses.
Task 3: Inferential Statistical Analysis
Task 3 compares the academic performance of students who use AI-based learning tools with students who do not use these tools.

The same StudentData.csv dataset was used for this analysis.

The following activities were completed:
1. Classified students into two comparison groups:
   - AI Tool Users
   - Non-AI Users
2. Calculated the number of students in each group.
3. Calculated the mean and standard deviation of both groups.
4. Applied Welch's Independent-Samples t-test.
5. Selected a significance level of 0.05.
6. Calculated the difference between group means and a 95% confidence interval.
7. Interpreted the statistical findings and hypothesis-testing decision.
Summary of Task 3 Results

Hypothesis Testing Results

Interpretation: The p-value (0.809) is greater than the significance level (0.05). Therefore, the analysis does not provide sufficient statistical evidence of a significant difference between the average examination marks of AI-tool users and non-AI users.
